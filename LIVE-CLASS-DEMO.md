# Live Interactive Classroom Demo

For the strongest presentation, open the application in two browser sessions: one teacher and one learner.

The teacher starts a confirmed session from **Sessions → Open Interactive Class → Start Live Class**. Both users then see live presence and the class timer. Topic completion, tasks, resources, saved notes, classroom chat, and quiz updates are synchronized through WebSockets. While a participant types in Shared Notes, the partner sees a live draft indicator. The learner can use **Raise Hand** and the teacher receives the alert immediately.

When the teacher selects **End Class & Unlock Quiz**, the session becomes `COMPLETED`. The learner can then answer the teacher-created multiple-choice assessment. The backend calculates and stores the score automatically.

This project does not include audio/video calling. Real-time collaboration is the live-class interaction feature used for the final project demonstration.
